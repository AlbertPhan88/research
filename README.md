# Research Notes

Source-checked studies of topics in software engineering and AI, published as static HTML via GitHub Pages.

Each study separates verified facts from assumptions and inferences, and cites the primary sources it was checked against.

## Layout

- `index.html` lists all topics.
- `topics/<slug>/index.html` holds one study per topic.
- `assets/style.css` is shared by every page.

To add a topic, create `topics/<slug>/index.html`, link `../../assets/style.css`, and add an entry to `index.html` and this README.
